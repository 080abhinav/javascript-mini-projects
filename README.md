# JavaScript Mini Projects 🚀

This repository contains a collection of small JavaScript projects that I built while learning and practicing **Vanilla JavaScript**, HTML, and CSS.  
Each project focuses on strengthening core concepts like DOM manipulation, events, state management, and browser APIs.

---

## 📂 Projects Included

### 🌦️ Weather App
A modern weather application that fetches real-time data using an API.

**Features:**
- Search weather by city name
- Clean and responsive UI
- Secure API handling using Netlify Functions
- Built with Fetch API and Serverless Functions

🔗 Live Demo: https://080weathernow.netlify.app/

📁 Folder: `Weather/`

---

### 📝 Todo List App
A simple yet functional todo application built using Vanilla JavaScript.

**Features:**
- Add and delete tasks
- Due date selection
- Prevent empty todos
- Persistent storage using `localStorage`
- Responsive layout
- Clean UI with proper alignment

🔗 Live Demo: https://080todo-list.netlify.app/  

📁 Folder: `todo/`

---

### ✊ Rock Paper Scissors Game
A classic Rock Paper Scissors game built with JavaScript.

**Features:**
- User vs computer gameplay
- Random computer moves
- Score tracking
- Simple and interactive UI

🔗 Live Demo: https://080rps.netlify.app/ 

📁 Folder: `rock-paper-scissor/`
